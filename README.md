## Project Portfolio Architecture

### 1. Advanced CGPA Calculator (`task1_CGPA_calculator.cpp`)
* **Core Purpose:** Designed to automate academic tracking and grade computation for students.
* **Key Engineering Highlights:** 
  * Implements dynamic data structures to process multi-semester credit hours and grade points.
  * Ensures robust error handling for invalid grade inputs and floating-point precision formatting.

### 2. Secure User Authentication System (`Task2_login_and_registration_system.cpp`)
* **Core Purpose:** A robust credential management and verification module mimicking enterprise authentication flows.
* **Key Engineering Highlights:**
  * Features secure user registration, session handling, and lookup protocols.
  * Implements strict string validation to safeguard against data corruption during login attempts.

### 3. Algorithmic Sudoku Solver (`Task3_Sudoku_Solver.cpp`)
* **Core Purpose:** An advanced computational puzzle solver utilizing optimization algorithms.
* **Key Engineering Highlights:**
  * Powered by optimized **Backtracking Recursion** algorithms to compute valid matrix permutations.
  * Efficiently processes complex 9x9 grids with minimal time and memory overhead.
